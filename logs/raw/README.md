# 원본 로그 (전문)

모델 응답을 수정하지 않고 그대로 저장합니다. 파일 이름 규칙:

| 파일 | 내용 |
|---|---|
| `A_v1_<모델>.md` | Run A: v1 간단 프롬프트 응답 |
| `B_v2_<모델>.md` | Run B: v2 시스템 프롬프트 응답 |
| `C_halluc_<모델>.md` | Run C: 환각 검증 질문 응답 |
| `D_conversation_<모델>.md` | Run D: 12턴 대화 전문 |

`<모델>`: `chatgpt`, `claude`, `gemini`

각 파일 맨 위에 모델명, 요금제, 날짜, 채널을 적습니다.
