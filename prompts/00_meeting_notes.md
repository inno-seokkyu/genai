# 테스트 입력: 회의 메모 원문 (가상 시나리오)

> 모든 모델에 **똑같이** 넣는 입력입니다. 가상의 회의이며 실명 대신 역할명만 사용했습니다.
> 이 메모는 일부러 지저분하게 만들었습니다: 결정/보류가 섞여 있고, 담당자·기한이 빠진 항목, 확정되지 않은 금액이 있습니다.

```
[회의 메모] 러닝허브 리뉴얼 주간 회의 — 2026-10-12(월) 14:00~15:10
참석: PM, 프론트엔드 리드, 백엔드 개발자, 디자이너, 마케팅 담당 (QA 담당 불참)

- PM: 베타 오픈 11/18(수)로 가자. 다들 동의.
- 프론트 리드: 마이페이지 개편이 생각보다 큼. 11/18 맞추려면 2주 정도 야근 필요할 듯. 주 15시간 정도?
- PM: 야근은 일단 보류, 범위 줄일 수 있는지 먼저 보자. 프론트 리드가 축소안 정리해서 금요일까지 공유.
- 디자이너: 디자인 외주 견적 1,200만원 받음. 이번 주 금요일까지 계약 여부 알려줘야 함.
- PM: 외주 진행하는 걸로. 계약 품의는 PM이 올림.
- 백엔드: 동시접속 늘어날 거라 서버 증설 필요. 월 85만원 추가, 최소 6개월.
- 마케팅: 오픈 맞춰 사내 홍보 예산 700만원 요청.
- PM: 서버 증설 OK. 마케팅 예산은 본부장 확인 후 다음 주에 확정.
- 정식 오픈 12월로 미루자는 얘기 나왔으나 결론 안 남. 다음 회의에서 다시.
- 백엔드: 결제 모듈 API 문서 언제 오는지 모름 → 누가 업체에 물어보기로 (담당 미정)
- 디자이너: 시안 1차 10/23(금)까지 공유
- QA 일정은 QA 담당 복귀 후 정하기로
- 다음 회의 10/19(월) 같은 시간
```

## 정답 키 (채점용, 모델에 넣지 말 것)

| 구분 | 정답 |
|---|---|
| 결정사항 | ① 베타 오픈 2026-11-18(수) ② 디자인 외주 진행(1,200만원) ③ 서버 증설(월 85만원, 최소 6개월) ④ 야근 보류, 범위 축소 우선 검토 |
| 보류/미확정 | 마케팅 예산 700만원(본부장 확인 후 다음 주 확정), 정식 오픈 12월 연기(결론 없음), QA 일정(QA 담당 복귀 후) |
| Action Items | 프론트 리드: 축소안 공유, 10/16(금) / PM: 외주 계약 품의, 기한은 원문에 없음(디자이너가 금요일 10/16까지 계약 여부 회신해야 하므로 그 전이 필요하다고 볼 수 있음) / 디자이너: 시안 1차, 10/23(금) / 결제 모듈 API 문서 문의: **담당 미정**, 기한 없음 / 마케팅 예산 확정: 본부장 확인 → 다음 주 |
| 후속 일정 | 다음 회의 2026-10-19(월) 14:00 |
| 함정 | 결제 모듈 담당을 지어내면 Fail, 12월 연기를 결정으로 쓰면 Fail, 마케팅 700만원을 확정으로 쓰면 감점 |
| 날짜 검증 | 2026-10-12=월, 10-16=금, 10-23=금, 11-18=수, 10-19=월 (Python으로 확인함) |
