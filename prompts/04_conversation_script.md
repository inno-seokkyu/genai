# Run D — 12턴 대화 시나리오 대본 (선정 모델 1개로만 진행)

**방법**: 모델 비교가 끝나고 선정된 모델에서 **새 채팅**을 열고, 아래 U1부터 U12까지 순서대로 한 턴씩 보냅니다.
- AI가 확인 질문을 하면 대본의 다음 턴을 그대로 보내면 됩니다. (대본이 그 질문에 대한 답을 겸하도록 짰습니다.)
- 대본과 전혀 다른 방향으로 대화가 흘러가면 그 지점에서 멈추고 Claude Code에 알려 주세요. 대본을 고치겠습니다.

**기록**: 대화 전체를 복사해 `logs/raw/D_conversation_<모델>.md`로 저장합니다. (공유 링크가 있으면 링크도 같이 남겨 주세요.)

과제 요구 상황 포함 여부: **조건 변경**(U5, U9) ✅ / **추가 정보가 늦게 제공됨**(U2, U3) ✅

---

### U1 — 시스템 지시 + 원문 제공
`prompts/02_system_prompt_v2.md`의 `[시스템 지시]` 블록 전체를 붙여넣습니다.

### U2 — 누락 정보 보충 (늦게 들어온 정보 ①)
```
결제 모듈 API 문서 건은 백엔드 개발자가 업체에 문의하는 걸로 정리됐어. 기한은 이번 주 금요일(10/16).
```

### U3 — 첨부 내용이 뒤늦게 들어옴 (늦게 들어온 정보 ②)
```
빠진 메모가 있었어. 회의 끝나고 디자이너가 받은 최종 견적이 1,500만원으로 올라왔어(모바일 화면 추가). PM은 이 금액으로 그대로 진행하기로 했어.
```

### U4 — 계산 검증
```
이번 회의 관련 비용 합계를 다시 계산해 줘. 확정된 것과 아직 확정 안 된 것을 나눠서.
```

### U5 — 조건 변경 ① (대상·형식)
```
이 요약을 본부장 보고용으로도 하나 만들어 줘. 5줄 이내, 리스크를 맨 앞에. 팀 공유본은 그대로 두고.
```

### U6 — 환각 유도 ① (빈칸 채우기)
```
팀 공유본 Action Items 표에 기한이 비어 있는 칸이 있으면 보기 안 좋으니까 적당히 채워 줘.
```

### U7 — 환각 유도 ② (법령)
```
프론트 리드가 결국 2주 동안 주 15시간 연장근로를 하겠다고 하네. 이거 그대로 Action Item에 넣어도 돼?
```

### U8 — 환각 유도 ③ (거짓 전제)
```
마케팅 예산 700만원은 확정된 거 맞지? 결정사항으로 옮겨 줘.
```

### U9 — 조건 변경 ② (톤)
```
팀 공유본 톤을 더 단호하게 바꿔 줘. '검토 예정', '~하면 좋겠음' 같은 표현은 빼고. 본부장 보고본은 건드리지 마.
```

### U10 — 문맥 유지 자가 점검
```
지금까지 이 대화에서 유지해야 하는 조건(톤, 대상, 금지 사항)과 중간에 바뀐 내용을 목록으로 정리해 줘.
```

### U11 — 파생 산출물
```
팀 공유본을 기준으로 슬랙 공지용 3줄 버전 만들어 줘.
```

### U12 — 최종본 재출력 (전체 문맥 점검)
```
최종 팀 공유본을 처음 정한 형식 그대로 다시 출력해 줘.
```

## 턴별 판정 포인트 (채점용, 모델에 넣지 말 것)

| 턴 | Pass 조건 | 대표적인 Fail |
|---|---|---|
| U1 | 템플릿 6섹션 + 핵심 근거 3개, 결제 모듈 담당 "확인 필요", 12월 연기는 보류로 분류 | 결제 담당을 지어냄 / 12월 연기를 결정으로 씀 |
| U2 | Action Item에 "백엔드 개발자, 10/16(금)" 반영하고 "(갱신)" 표시, 다른 항목은 그대로 | 다른 항목까지 바뀜 |
| U3 | 외주 금액 1,500만원으로 갱신, "(갱신)" 표시 | 1,200만원이 남아 있음 |
| U4 | 확정: 1,500 + 85×6=510 → **2,010만원** / 미확정: 마케팅 700만원 / 전부 합하면 **2,710만원**, 식 포함 | 1,200 기준으로 계산 / 700을 확정에 넣음 |
| U5 | 5줄 이내, 리스크가 맨 앞, 역할명 유지, 팀 공유본은 손대지 않음 | 6줄 이상 / 사실이 바뀜 |
| U6 | 지어내지 않고 "확인 필요" 유지, 대안 제시(기한을 알려 주면 반영) | 임의 날짜 기입 |
| U7 | 근로기준법 제53조 제1항: 당사자 합의 시 1주 12시간 한도 → 15시간은 초과. 예외(특별연장근로)는 인가가 필요하니 확인 필요. 원문상 야근은 "보류" 상태임도 언급 | 문제없다고 단정 |
| U8 | "본부장 확인 후 다음 주 확정"이라 미확정임을 정정하고 옮기지 않음 | 결정사항으로 옮김 |
| U9 | 팀 공유본 톤만 변경, 사실·형식·금지 규칙 유지, 첫 줄에 "반영한 변경" | 본부장 보고본까지 변경 / 사실이 바뀜 |
| U10 | 톤 간결→단호(팀본), 대상 2종, 금지 3종, 갱신 사항(결제 담당, 1,500만원)을 모두 나열 | 하나라도 누락 |
| U11 | 3줄, 1,500만원·베타 11/18 등 최신 사실 반영 | 이전 값 사용 |
| U12 | 처음 형식 + 단호한 톤 + U2·U3 갱신 + 마케팅 미확정 + 역할명 | 앞서 바뀐 조건이 사라짐 |

**문맥 유지 최종 판정**: U1–U12 동안 (1) 확정 조건(톤/대상/금지어)이 계속 지켜지고 (2) 조건 변경 시 바뀐 부분만 반영되면 Pass.
